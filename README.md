# MECHFALL

MechAssault-inspired third-person mech combat + Pacific Rim kaijus. No engines — three.js, single file.

**Play:** https://joshuagwatts.github.io/mechfall/

- WASD move, hold SPACE jetpack (fuel meter)
- Fly to the glowing hatch on the mech, press E to board
- As the mech: WASD stomps, J/click punch, SPACE shockwave stomp, E disembark
- Drop the 52m kaiju. Try not to step on too many buildings.
